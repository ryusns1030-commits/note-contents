# note記事管理台帳｜私が使ってきたAI活用のすべて

## 制作時の運用

1. 無料①〜④・有料①〜③を呼び出すたびに、指定のプロンプトと最新版の台帳を確認する。選定前は近い記事の本文を参照できる範囲で読み、読者の悩み・使う方法・得られる学び・次に取れる行動を比較する。
2. 提供価値が同じ場合は既存記事への追記候補とする。同じ実体験を扱う場合でも、解決する悩みや具体的な方法、読者が実行できる行動に明確な違いがあり、独立して役立つものは関連記事と違いを記録して採用できる。
3. テーマ選定、原稿完成、公開準備、公開確認の各時点で同じ行を更新する。制作日は本文の完成日、公開日は実際の公開日を記録する。未確認は推定せず「未確認」とする。正式なテーマIDは確認できた場合に記入する。
4. Notionを更新の起点とし、GitHubにも照合用の情報を反映する。公開リポジトリには匿名化した記事情報を記録する。本文や公開URLの参照先は確認できたものを登録する。
